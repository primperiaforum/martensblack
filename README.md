# MARTENS_BLACK

Сайт конференции `АГРОПРОДМАШ 2026 / Стратегические вызовы АПК: Готовая еда`.

Проект живет в двух формах:

- обычный статический сайт в корне репозитория;
- подготовленный экспорт для ручной вставки в Tilda.

## Основные файлы

- `index.html` - основной HTML исходного сайта.
- `style.css` - основной CSS исходного сайта.
- `script.js` - интерактив: меню, табы программы, аккордеоны, lightbox, cookie banner, canvas-анимации.
- `Text-Fonts-Sizes.html` - таблица текстов сайта с размерами, жирностью и шрифтами для основной desktop-версии.
- `APM_logo.png`, `expocentr_logo.svg`, `imperia-forum_logo.svg` - логотипы.
- `IMG_5091.MP4` - видео в обложке.
- `cookie.html` - страница про cookie.
- `Политика_конфиденциальности_интернет_сайта_—_Империя_Форум.pdf` - политика обработки персональных данных.

## Tilda-экспорт

Рабочая папка:

`tilda_clean_export/`

Самый важный файл для Tilda:

`tilda_clean_export/PASTE_THIS_STYLE_IN_TILDA.html`

Его нужно вставлять целиком один раз в отдельный HTML-блок сверху страницы. Внутри уже есть `<style>...</style>`.

Основные файлы для текущей Tilda-схемы:

- `tilda_clean_export/tilda-before-form.html` - сайт до no-code формы регистрации.
- `tilda_clean_export/tilda-after-form.html` - сайт после no-code формы регистрации.
- `tilda_clean_export/tilda.css` - тот же CSS без обертки `<style>`.
- `tilda_clean_export/tilda.js` - JS для вставки один раз перед `</body>`.

Дополнительные/служебные файлы:

- `tilda_clean_export/tilda-html.html` - полный HTML без встроенной формы; не является главным файлом для текущей split-схемы.
- `tilda_clean_export/tilda-after-form-hotfix.html` - аварийная запасная вставка для блока после формы; в нормальной схеме не нужна.
- `tilda_clean_export/README.md` - подробная инструкция по Tilda.

## Текущая рабочая схема Tilda

Сайт в Tilda разбит так:

1. Верхний HTML-блок со стилями: содержимое `PASTE_THIS_STYLE_IN_TILDA.html`.
2. Первый HTML-блок сайта до формы: `tilda-before-form.html`.
3. No-code форма Tilda.
4. Второй HTML-блок после формы: `tilda-after-form.html`.
5. JS вставляется один раз.

CSS специально написан через:

```css
:where(#tilda-custom-site, .tilda-custom-site)
```

Так он работает и со старым wrapper `id="tilda-custom-site"`, и с раздельными wrapper-блоками `.tilda-custom-site`.

## Важные правила

- Не вставлять CSS несколько раз на одну страницу Tilda.
- Не смешивать старые и новые версии `style`-вставок.
- Не собирать Tilda-версию из опубликованной страницы: Tilda портит структуру и может превращать части кода в видимый текст.
- Для Tilda брать код только из `tilda_clean_export/`.
- Если блок после формы снова выглядит как сырой HTML, значит стили не подключились или подключилась старая CSS-версия.

## Обновление формы 2026-07-20
