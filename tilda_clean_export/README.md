# Чистый экспорт для Tilda

Эти файлы пересобраны из нормальных исходников `index.html`, `style.css`, `script.js`, а не из опубликованной Tilda-страницы.

## Как вставлять

1. Самый надежный вариант: содержимое `PASTE_THIS_STYLE_IN_TILDA.html` вставь один раз в отдельный HTML-блок сверху страницы. Там уже есть `<style>...</style>`.
2. Первый HTML-блок T123: вставь содержимое `tilda-before-form.html`.
3. Потом поставь no-code форму Tilda. Желательно задать ей якорь `reg`, чтобы кнопки регистрации скроллили к ней.
4. Второй HTML-блок T123: вставь содержимое `tilda-after-form.html`.
5. JS из `tilda.js` вставь один раз перед `</body>`, обернув в `<script>...</script>`.

## Что исправлено

- HTML больше не содержит `<!DOCTYPE>`, `<html>`, `<head>`, `<body>` и подключений `style.css/script.js`.
- Встроенная форма регистрации удалена из кода: используется no-code форма Tilda между файлами `tilda-before-form.html` и `tilda-after-form.html`.
- Кнопки регистрации ведут на якорь `#reg`; такой же якорь нужно поставить на no-code форму Tilda.
- Импорт Google Fonts удален, CSS использует `PT Sans` из настроек сайта Tilda.
- Разметка сохранена с нормальными переносами и отступами из исходного файла.
- Все локальные изображения, видео, PDF и cookie-ссылка заменены на абсолютные URL.
- CSS заскоуплен под `:is(#tilda-custom-site, .tilda-custom-site)`, чтобы он работал и со старым `id`, и с новыми split-блоками на классе.
- В конец CSS встроен постоянный fallback для блока после формы: организаторы, контакты и футер не должны разваливаться после перезагрузки.

## Важно

Не вставляй несколько копий CSS/JS на одну страницу. Именно это обычно плодит десятки лишних стилей на каждом элементе и тормозит страницу.

Если используешь обновленный `tilda.css`, отдельный файл `tilda-after-form-hotfix.html` больше не нужен. Он оставлен только как аварийная проверочная вставка.
