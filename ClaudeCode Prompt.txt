# РОЛЬ И КОНТЕКСТ
Ты — Senior Frontend-разработчик и UX/UI-архитектор с опытом создания высококонверсионных B2B-лендингов для отраслевых конференций. Твоя задача — сгенерировать полностью рабочий, адаптивный одностраничный сайт (SPA-лендинг) для регистрации на деловую конференцию «АГРОПРОДМАШ 2026: Стратегические вызовы АПК — готовая еда».

# ЦЕЛЕВАЯ АУДИТОРИЯ И ТОН
- Аудитория: B2B, русскоязычная. Собственники, топ-менеджеры, коммерческие директора, главные технологи производителей готовой еды, ритейла, HoReCa и кейтеринга.
- Тон: Экспертный, деловой, технологичный, без «маркетингового шума». Визуал и копирайт должны транслировать статусность, прозрачность и практическую ценность.
- Единственное целевое действие (CTA): Бесплатная регистрация. Все остальные элементы работают на доверие и конверсию в эту форму.

# ТЕХНИЧЕСКИЙ СТЕК
- HTML5 (семантическая верстка, доступность ARIA, валидация W3C)
- CSS3 (CSS Custom Properties, Flexbox/Grid, mobile-first, без внешних UI-фреймворков для легкости дальнейшей правки)
- Vanilla JavaScript (ES6+, без jQuery)
- Файловая структура на выходе: `index.html`, `style.css`, `script.js`
- Все изображения: заглушки через `https://placehold.co/` с точными размерами и `alt`-атрибутами
- Адаптивность: корректное отображение на mobile (<768px), tablet (768–1024px), desktop (>1024px)

# ДИЗАЙН-СИСТЕМА И UX
- Цвета: `--bg-primary: #0F172A` (тёмно-синий), `--bg-secondary: #F8FAFC`, `--accent: #059669` (изумрудный/технологичный), `--text-main: #1E293B`, `--text-muted: #64748B`
- Типографика: Inter или системный sans-serif. Заголовки: 700/600, текст: 400. Размеры по модульной сетке.
- Отступы: `--space-xs: 8px`, `--space-sm: 16px`, `--space-md: 24px`, `--space-lg: 48px`, `--space-xl: 80px`
- Кнопки: `padding: 14px 28px`, `border-radius: 8px`, `transition: all 0.2s`
- Hover-эффекты: только на CTA и ссылках. Избегать анимаций, снижающих производительность.
- Доступность: `aria-expanded`, `aria-controls` для аккордеонов, `tabindex`, контраст > 4.5:1, фокус-состояния.

# ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
- Плавный скролл к якорям
- Аккордеон программы: только одна раскрытая тема одновременно (или независимое раскрытие, на твой выбор, но с плавной анимацией высоты)
- Лайтбокс галереи: закрытие по ESC, клику вне изображения, стрелки влево/вправо
- Валидация формы в реальном времени, подсветка ошибок
- Mobile-first: все сетки перестраиваются, навигация сворачивается в бургер-меню на <768px
- Оптимизация: `loading="lazy"` для изображений, минимизация reflow, чистый DOM

# ФОРМАТ ВЫВОДА
1. Выведи полную структуру файлов
2. Предоставь код каждого файла целиком в отдельных блоках: `index.html`, `style.css`, `script.js`
3. В коде оставь комментарии `<!-- TODO: -->` только там, где нужна замена контента или подключение бэкенда
4. После кода кратко опиши, как запустить проект локально (просто открыть index.html или через live-server)
5. Не добавляй лишних фреймворков, не используй inline-стили, кроме критических. Весь CSS в `style.css`, весь JS в `script.js`.
